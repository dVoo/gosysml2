## License Summary

**GNU General Public License v3.0 (GPLv3)**

Key points:
- ✅ **Free to use** - Anyone can use the library
- ✅ **Free to modify** - Source code can be changed
- ✅ **Free to distribute** - Can be shared with others
- ✅ **Copyleft** - Derivative works must also be GPLv3
- ✅ **Source disclosure** - Distributed binaries must include source

## Why GPLv3?

GPLv3 was chosen to:
1. Ensure the library remains free and open source forever
2. Protect users' rights to modify and share the code
3. Prevent proprietary forks from locking away improvements
4. Align with open standards (SysML is an open standard)
