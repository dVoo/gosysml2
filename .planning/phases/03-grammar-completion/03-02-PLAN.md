## Implementation Notes

ControlNodes are used in activity diagrams to control flow:
- ForkNode: splits flow into parallel branches
- JoinNode: synchronizes parallel branches
- MergeNode: combines alternative flows
- DecisionNode: conditional branching (like if/else)

Occurrences model time-based instances:
- OccurrenceDefinition: defines occurrence types
- OccurrenceUsage: uses occurrence types
- IndividualDefinition: specific individual instances
- EventOccurrenceUsage: event-based occurrences

BindingConnectors bind values between features.
Successions define predecessor-successor relationships.
