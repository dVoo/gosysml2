## Library Structure

The standard library is organized as:
- `./libraries/sysml.library/Domain Libraries/` - Analysis, Cause and Effect, Geometry, Metadata, Quantities and Units
- `./libraries/sysml.library/Kernel Libraries/` - Base, Collections, ControlFunctions, etc.
- `./libraries/sysml.library/Systems Library/` - Systems-level definitions

Library files use `standard library package` syntax and contain definitions like:
```sysml
standard library package ScalarValues {
    attribute def Boolean;
    attribute def Integer :> Rational;
}
```

## Current State

The parser currently handles import statements syntactically but doesn't resolve them to actual library files. The `Model.findElement()` method looks up elements by qualified name within the current model only.
</context>
