Output: Updated parser that resolves imports and qualified names using the library registry.

## Current Parse Flow

1. ParseString/ParseFile calls `parseWithSource`
2. Low-level parser generates AST
3. `buildModel` walks AST and creates model elements
4. `model.BuildIndex()` creates element index
5. `model.ResolveReferences()` resolves internal references

## Integration Points

Need to:
1. Add library registry to parse configuration
2. Load standard library before parsing (if not already loaded)
3. Resolve import statements to library packages
4. Resolve qualified names (e.g., `ISQ::mass`) to library elements
5. Merge library elements into model or keep separate with references

## Import Statement Handling

Current: `EnterImport_` in parse.go creates Import element with namespace string
New: Should also resolve to library package if it's a library import

## Qualified Name Resolution

Current: `model.findElement` searches within the model only
New: Should also search in library registry for qualified names like `ISQ::mass`
