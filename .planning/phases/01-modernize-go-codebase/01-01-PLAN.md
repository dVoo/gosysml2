<task type="auto">
  <name>Task 2: Modernize low-level wrapper package</name>
  <files>gosysml2/low/lexer.go, gosysml2/low/parser.go, gosysml2/low/errors.go, gosysml2/low/parser_test.go</files>
  <action>
Modernize the three files in `gosysml2/low/` with modern Go 1.25 patterns. Keep the public API stable -- same function signatures, same types -- but improve internals.

**errors.go:**
- Make `SyntaxError` implement `error` interface with `Unwrap()` support so it works with `errors.Is`/`errors.As`.
- Make `ParseErrors` implement the `error` interface with proper `Unwrap()` returning a joined error (use `errors.Join` from Go 1.20+).
- Add an `Error()` method on `ParseErrors` that uses `strings.Builder` efficiently (already does, but verify no `fmt.Sprintf` in hot paths).
- In the `ParseErrors.Error()` method, preallocate the Builder with `sb.Grow()` based on estimated output size.
- The `ErrorCollector` already preallocates with cap 8 -- keep that.

**lexer.go:**
- Add error wrapping to `TokenName` -- instead of returning "UNKNOWN" for out-of-range tokens, this is fine as-is (no error path). Leave stable.
- In `AllTokens()`, the preallocated capacity of 256 is good. Keep it.
- No major changes needed -- this file is already well-written.

**parser.go:**
- Add `context.Context` support to the `Parser` struct and constructors. Add a `WithContext(ctx context.Context) ParseOption` that stores context in parserConfig. This enables cancellation for long-running parses. If no context provided, use `context.Background()`.
- Add error wrapping in convenience functions `Parse`, `ParseBytes`, `Validate`, `ValidateBytes` -- wrap returned errors with source context using `fmt.Errorf("parsing input: %w", ...)`. Since these return `*ParseErrors` (not error), add a helper method `ParseErrors.Err() error` that returns nil if no errors, or the ParseErrors as an error if there are errors. This enables idiomatic `if err := result.Err(); err != nil` patterns.
- Keep the lazy token consumption pattern (no tokens.Fill()).

**parser_test.go:**
- Add test for `ParseErrors.Err()` helper.
- Add test for `context.Context` cancellation (use `context.WithCancel`, cancel before parse, verify behavior).
- Ensure all existing tests still pass.

IMPORTANT: Do NOT modify any files in `gosysml2/internal/parser/`. Only modify files in `gosysml2/low/`.
  </action>

  </verify>
