**errors.go -- Add Unwrap and errors.Is/As support:**

- Add `Unwrap() error` to the `Error` type so individual errors can be checked with `errors.Is`/`errors.As`.
- Add `Unwrap() []error` to `ParseError` using Go 1.20+ multi-error unwrapping (returns all individual errors). This enables `errors.Is(parseErr, targetErr)` to check any of the contained errors.
- Add `Err() error` convenience method on `ParseError` that returns nil if no errors, or the ParseError itself if there are errors. This enables idiomatic:
  ```go
  if err := result.Errors.Err(); err != nil { ... }
  ```
- In `ParseError.Error()`, preallocate the strings.Builder with `sb.Grow()` based on estimated output size (e.g., `sb.Grow(len(e.Errors) * 80)`).
- Add `Is(target error) bool` and `As(target interface{}) bool` if needed for proper error chain traversal.

**parse.go -- Error wrapping with context:**

- `ParseFile`: Wrap file read errors with filename context:
  ```go
  return nil, fmt.Errorf("reading %s: %w", filename, err)
  ```
  Currently it constructs a `ParseError` manually. Instead, wrap the os error properly so the original error is preserved in the chain.

- `ParseReader`: Same treatment -- wrap io.ReadAll errors with source context.

- `ParseDirectory` and `ParseDirectoryParallel`: Wrap filepath.WalkDir errors:
  ```go
  return nil, fmt.Errorf("walking directory %s: %w", dir, err)
  ```

- `ParseDirectoryStream`: Same treatment for WalkDir errors.

- `parseWithSource` and `ParseBytes`: These work with low.ParseErrors. The conversion in `convertFromLowLevel` should preserve error chains. Update `convertFromLowLevel` to use `fmt.Errorf` with `%w` wrapping the original low-level errors so the chain is maintained.

**parse.go -- modelBuilder optimizations:**

1. **Reduce repetitive parent-addition code.** The Enter* methods for PartDefinition, PartUsage, PortDefinition, PortUsage, AttributeDefinition, AttributeUsage each have 10-20 line switch statements for adding to parent. Create a helper method:
   ```go
   // addToParent adds an element to the current parent with proper type handling.
   func (b *modelBuilder) addToParent(elem Element) {
       parent := b.getCurrentParent()
       if parent == nil {
           return
       }
       // Set parent reference
       if setter, ok := elem.(interface{ SetParent(Element) }); ok {
           setter.SetParent(parent)
       }
       // Use AddChild if available (handles type tracking)
       switch p := parent.(type) {
       case interface{ AddChild(Element) }:
           p.AddChild(elem)
       default:
           // Fallback: if parent doesn't have AddChild, just set parent
       }
   }
   ```
   Wait -- all the concrete types already have `AddChild` methods, but they don't share a common `AddChild` interface. The `Element` interface doesn't include `AddChild`.

   Better approach: Add an `ElementContainer` interface:
   ```go
   // ElementContainer is implemented by elements that can hold children.
   type ElementContainer interface {
       Element
       AddChild(child Element)
   }
   ```
   Then simplify:
   ```go
   func (b *modelBuilder) addToParent(elem Element) {
       parent := b.getCurrentParent()
       if parent == nil {
           return
       }
       if container, ok := parent.(ElementContainer); ok {
           container.AddChild(elem)
       }
   }
   ```

   Note: The `ElementContainer` interface should be declared in model.go. Since this plan does not modify model.go (Plan 02 handles that), add `ElementContainer` to THIS plan's scope in errors.go or parse.go as a local interface. Actually, since `addToParent` is a private helper, define it as a local interface in parse.go:
   ```go
   // childAdder is implemented by elements that can hold children.
   type childAdder interface {
       AddChild(child Element)
   }
   ```

   Apply `addToParent` to: EnterPartDefinition, EnterPartUsage, EnterPortDefinition, EnterPortUsage, EnterAttributeDefinition, EnterAttributeUsage, and all other Enter* methods that have the switch-on-parent pattern. This should eliminate ~200 lines of repetitive switch statements.

2. **Extract location helper.** Every Enter* method has the same 7-line block to create a Location from ctx.GetStart()/GetStop(). Extract a helper:
   ```go
   func locationFromContext(ctx interface {
       GetStart() antlr.Token
       GetStop() antlr.Token
   }) Location {
       loc := Location{
           Line:   ctx.GetStart().GetLine(),
           Column: ctx.GetStart().GetColumn(),
       }
       if ctx.GetStop() != nil {
           loc.EndLine = ctx.GetStop().GetLine()
           loc.EndColumn = ctx.GetStop().GetColumn()
       }
       return loc
   }
   ```
   Apply to ALL Enter* methods (30+ occurrences).

3. **Preallocate modelBuilder stacks.** In `buildModel`, preallocate the element and package stacks with reasonable initial capacity:
   ```go
   builder := &modelBuilder{
       model:        model,
       elementStack: make([]Element, 0, 16),
       packageStack: make([]*Package, 0, 8),
   }
   ```
